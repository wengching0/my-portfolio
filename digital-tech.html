數位科技概論 (Introduction to Digital Technology)

本課程涵蓋 GitHub 版本控制實作、HTML5 語意結構與多媒體應用，以及 CSS3 版型配置與無障礙網頁檢測。

HTML 基礎活動實作 (活動 01-04)

  • 活動 01：文字層級與語意標籤

    練習使用 h1-h3 標題層級、段落 p、粗體 b、斜體 i、上下標 sub/sup 設計「水與生活」科學活動頁面。

    → 查看活動 01 成品頁面（水與生活）
    HTML5

  • 活動 02：多媒體元件整合

    嵌入 img (透明 PNG/SVG 向量圖)、audio 與 video 元件，並設定替代文字 alt 與控制屬性。

    → 查看活動 02 成品頁面（校園自然觀察）
    Media

  • 活動 03：紙橋挑戰社：活動準備頁

    運用 HTML 結構化標籤（有序/無序清單與表格）進行內容排版，練習小組分工與資料呈現。

    → 查看活動 03 成品頁面（紙橋挑戰社）
    Plan

  • 活動 04：放學後社團體驗表

    運用 HTML 表單元件（單行/多行文字欄位、下拉選單、單選/複選與停用按鈕）練習介面設計與元件互動。

    → 查看活動 04 成品頁面（社團體驗表）
    Form

CSS 樣式與無障礙設計 (活動 05-09)

  • 活動 05：同一份內容，換一種風格

    運用 CSS 進行樣式與色彩控制（標題字體大小、內文行高、卡片留白 padding 與圓角邊框）。

    → 查看活動 05 成品頁面（色彩與風格控制）
    CSS Style

  • 活動 06：CSS Grid 整頁版型設計

    比較單欄、兩欄、三欄與側欄主內容等不同 Layout 佈局適用的內容類型。

    → 查看活動 06 成品頁面（Grid 版型配置）
    Layout

  • 活動 07：Flexbox 卡片排版

    使用 Flex 彈性盒排列卡片，搭配 object-fit: cover/contain 控制圖片等高與裁切。

    → 查看活動 07 成品頁面（Flexbox 排版）
    Flexbox

  • 活動 08：RWD 響應式網頁設計

    使用 @media (max-width: 600px) 媒體查詢，實現電腦版多欄與手機版單欄之自動切換。

    → 查看活動 08 成品頁面（RWD 響應式設計）
    RWD

  • 活動 09：無障礙網頁檢測 (WAVE)

    修正色彩高對比度、補齊 label for 關聯，並實作 focus-visible 鍵盤焦點導覽。

    → 查看活動 09 成品頁面（無障礙檢測）
    Accessibility
